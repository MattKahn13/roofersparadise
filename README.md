# RoofersParadise

A free hail map for roofers -- see where hail hit (NOAA MRMS radar), look up any address, and
get real-time alerts. Free alternative to paid storm-tracking tools.

One FastAPI app: serves the map + Google sign-in + alerts UI. See DEPLOY.md for the free
Render + Turso + GitHub Actions deploy. Not affiliated with the National Weather Service.
